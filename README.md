## 🌟 คุณสมบัติหลัก (Features)

* **บันทึกรายการ:** เพิ่ม รายรับ (Income) และ รายจ่าย (Expenses) พร้อมระบุหมวดหมู่และหมายเหตุ
* **มุมมองรายวัน (Daily View):** สรุปยอดรวมรายรับ-รายจ่าย และแสดงรายการทั้งหมดที่เกิดขึ้นในแต่ละวัน
* **มุมมองรายเดือน (Monthly View):** สรุปภาพรวมการเงินประจำเดือน พร้อมเปรียบเทียบสัดส่วนการใช้จ่าย
